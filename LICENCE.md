## 🧩 About

**The First Descendant GUI** is a comprehensive mod menu for The First Descendant featuring an overlay menu, script runner, stat viewer, quality-of-life toggles, and a clean GUI.

Based on popular community tools and inspired by similar overlay projects.

## ✨ Features

### 🎮 Core GUI
- Overlay Menu — toggleable in-game GUI with hotkey
- Script Runner — execute custom Lua scripts
- Stat Viewer — display real-time player and weapon stats
- Quality-of-Life Toggles — auto-loot, auto-skip, and more
- Config Profiles — save and load GUI configurations

### 🎨 Customization & Unlocks
- Unlock All Skins — access all cosmetic items
- Custom Crosshair — choose from multiple crosshair styles
- UI Themes — dark and light GUI themes
- Colored Rarity Highlights — enhance item visibility

### 🏋️ Practice & Training
- Practice Mode — infinite retries on any mission
- Instant Mission Unlock — unlock all missions
- Damage Multiplier — adjust outgoing damage for testing
- Godmode — toggle invincibility for testing
